# 실제 대중교통 경로 등록 (1.0.7+4024)

## 사용 방법

내 일정에서 같은 날의 서로 겹치지 않는 두 일정 사이 **경로 추가**를 누른다.
출발·도착 장소와 출발시간을 확인하고 **경로 찾기**를 누르면 Google Routes가 반환한 경로 중 최대 3개를 선택할 수 있다. 같은 노선의 다른 출발편보다 서로 다른 이동 경로를 우선 표시한다.

**지도로 보기**를 누르면 기존 Kakao Maps SDK를 사용하는 팝업에서 출발·도착점과 구간별 경로를 확인할 수 있다. 구간을 누르면 해당 구간의 A/B 승하차 위치와 제공되는 상세 노선으로 확대한다. 전체 화면에는 출발·도착 A/B 두 마커만 표시해 겹침을 줄인다. 지도를 확대·이동할 수 있으며 **전체 경로 보기**로 다시 맞출 수 있다. 상세 시간표는 기본적으로 접혀 있으며 펼쳐서 볼 수 있다.

- 버스번호, 지하철 호선, 기차 노선명
- 구간별 승하차 정류장·역, 운행 방향, 정류장 수, 운수사
- 제공되는 구간별 출발·도착 시간표
- 전체 소요시간과 도착 예정시간, 다음 일정 지각 경고

선택한 뒤 **이 경로를 일정에 추가**를 누르면 기기에 저장한다. 저장한 이동 계획을 다시 누르면 상세정보 확인·재검색·삭제가 가능하다.

## 데이터 처리

`GoogleApi.transitJourneys`는 `computeAlternativeRoutes: true`로 실제 Google Routes API를 호출한다.
노선번호는 `nameShort`, 없으면 `name`을 쓴다. 동일 노선을 재탑승하는 경우 순서와 중복을 유지한다.
교통수단은 공급자의 `vehicle.type`으로 판별한다. 제공되지 않은 역·시간·열차번호는 만들지 않는다.

도착 예정시간은 마지막 탑승 구간의 실제 응답 시간표에 마지막 도보 구간 시간을 더한다.
시간표가 없는 기존 저장 경로는 이전 방식(출발시간 + 소요시간)으로 호환된다.
경로 좌표·교통수단·시설 ID와 구간 상세·도착시간은 재저장 후에도 보존한다.

저장 경로는 기존 교통 영향 판단에 연결된다. 노선명만으로 공식 노선 ID를 임의 생성하지 않으며,
공급자·지역·수단·유효기간이 확인되는 기존 레퍼런스로만 시설 ID를 확인한다.

## 범위

- 일정 편집의 **이동 방법 직접 입력**은 그대로 수동 입력이다. 이 기능의 진입점은 두 일정 사이 **경로 추가**다.
- 경로·시간표 조회 및 등록이며 열차 예매, 잔여석, 실시간 버스 위치·도착 지연 조회는 포함하지 않는다.
- 특정 KTX 열차번호 등은 현재 응답 필드에서 제공하지 않는다. 기차 노선과 승하차역·시간표만 표시한다.
- 검색 가능 지역·기간·경로는 Google 제공 범위를 따른다. 결과가 없거나 API 호출이 실패하면 가짜 경로로 대체하지 않는다.
- 기기별 저장이며 Google Calendar 일정 설명이나 다른 기기에 동기화하지 않는다.

## 지도 좌표 누락 처리 (1.0.7)

2026-11-15 실제 서울시립과학관→청주대학교 API 응답에서 시외·고속버스 구간의 폴리라인이 출발·도착 두 점만 제공되는 것을 확인했다. 이런 구간을 실제 운행 선처럼 직선으로 잇지 않는다. 구간별 폴리라인을 따로 요청·저장하고, 3점 미만이거나 연속 좌표 사이에 5km 넘는 간격이 있는 불완전한 선은 그리지 않는다. 도보나 서로 다른 탑승 구간 사이도 임의로 잇지 않는다. 상세 좌표가 없는 구간은 안내문과 승하차 위치만 표시한다. 자동차 경로로 버스 노선을 대체하지 않는다.

기존 저장 경로를 열 때 상세 좌표가 없으면 같은 노선·승하차역·출발/도착시각이 모두 일치하는 경로의 좌표만 보완한다. 다른 출발편으로 바꾸지 않으며 실패하면 기존 위치 정보만 유지한다.

### Android 구간 전환 화면 갱신

상세선 제공 여부에 따라 안내문을 없애면 지도 영역 높이도 변해 네이티브 GL SurfaceView가 재배치된다. 구간 선택과 상세 좌표 조회 완료 시 지도 크기가 바뀌지 않도록 안내 영역을 고정하고, Flutter 프레임 배치 완료 후 네이티브 오버레이를 갱신한다. 상세선 제공 구간·누락 구간·전체를 오가며 지도 영역의 위치와 크기가 동일한지 회귀 테스트한다.
